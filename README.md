# 📑 김승현의 아카이브 사이트

프로필 · 학습 기록 · 여행 앨범을 한곳에 모은 **개인 아카이브 웹사이트**입니다.
옛날 데스크탑 창(레트로 UI) 감성으로 꾸몄으며, 순수 HTML/CSS/JavaScript로 만들었습니다.

- **레이아웃**: Flexbox · Grid 기반 멀티 컬럼 구성
- **반응형**: 화면 폭 786px 이하에서 1열로 재배치
- **인터랙션**: 실시간 날씨(Open-Meteo API), 미니게임 4종, 편리한 도구 2종
- **기술**: HTML5 시맨틱 태그, CSS3 애니메이션, Vanilla JS (프레임워크 없음)

---

## 🗂 UI 구성도

```
index.html (HUB)
│
├─ 🖥 바로 가기            → 각 페이지로 이동하는 데스크탑 아이콘 (nav)
│
├─ main
│   ├─ 🖍 공지사항          → 최신 소식 (칠판 스타일)
│   └─ 📷 베스트 샷         → 대표 사진 1장
│
├─ aside
│   ├─ ⚙ 실시간 날씨       → 현재 위치 날씨 자동 표시
│   ├─ 🌍 세계 날씨        → 도시 선택 시 해당 도시 날씨
│   ├─ 🎮 미니게임 천국     → 숫자야구 · 도토리찾기 · 화살피하기 · 사다리타기
│   └─ 🧰 편리한 도구       → 학점 계산기 · 챙길 품목 보기
│
└─ 📞 연락 방법 (footer)

── 개별 페이지 ──────────────────────────────
🧑 myProfile.html   프로필 (미니홈피 · 바인더 다이어리 컨셉)
🗓 myClass.html     강의 시간표 & 주간 식단표 (table)
🌴 myHoliday.html   휴일 일정
🖼 myTrip.html      여행 사진 앨범 (필름사진 · 영상 · 음성)
✉️ signUp.html      회원 가입 폼  ──▶  signupResult.html (가입 완료)
```

## 🔀 UI 플로우

```
                        ┌─────────────────┐
                        │   index.html    │  ◀── 시작 지점 (HUB)
                        │   (바로 가기)     │
                        └────────┬────────┘
                                 │  아이콘 클릭
     ┌───────────┬───────────┬───┴───────┬───────────┐
     ▼           ▼           ▼           ▼           ▼
 myProfile   myClass    myHoliday     myTrip       signUp
   프로필     시간표/식단     휴일 일정      여행 앨범     회원가입 폼
                                                     │ 제출
                                                     ▼
                                              signupResult
                                               가입 완료

  ※ 각 페이지 → "🏠 홈" 링크로 index.html 복귀

── index.html 내부 인터랙션 (페이지 이동 없음) ──
  날씨 위젯   : 도시 선택 ──▶ Open-Meteo API 호출 ──▶ 결과 표시
  미니게임    : 버튼 클릭 ──▶ 팝업 창(모달) 열림 ──▶ 플레이 ──▶ 닫기
  편리한 도구 : 버튼 클릭 ──▶ 학점 계산 / 품목 목록 표시
```
